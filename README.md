# Portfolio

Personal portfolio site for Pratik Shrivastava — hero, about, projects, experience, education, skills, and contact sections, built with TanStack Start, React, and Tailwind CSS.

## Development

```sh
npm i
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Editing content

All copy — profile info, projects, experience, education, and skills — lives in `src/routes/index.tsx` as plain data objects near the top of the file (`PROFILE`, `PROJECTS`, `EXPERIENCE`, `EDUCATION`, `SKILLS`, `ABOUT_FACTS`). Update those to change the site's content.
